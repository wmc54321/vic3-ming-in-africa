# Ming in Africa Mod Files

This directory is the loadable Victoria 3 mod.

Use the repository root documentation for design and implementation notes:

- `../../README.md` for the public project introduction.
- `../../docs/agent-handoff.md` for agent onboarding.
- `../../docs/implementation-map.md` for implemented systems and file ownership.

Generated history files should be regenerated from the repository root with `tools/generate_initial_mod.ps1`, using `VICTORIA3_GAME_ROOT` from `.env.local` or an explicit `-GameRoot` argument.
